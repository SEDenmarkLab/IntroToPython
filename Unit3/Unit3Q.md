# Unit 3: Iterables: Lists, Tuples, Dicts, and Sets

Here is a list of questions/comments you should be able to answer:

* What is an "iterable"?
* What is an "iterator"?
* What is the difference between a list, tuple, dict, and set?
* What is a generator? Why might you use this over a traditional iterable object?
* Should you iterate over a numpy array? When might you utilize a list over a numpy array?
* What are the `enumerate`, `range`, `len`, `count`, and `zip` functions? Why might you use the numpy `arange` function over the traditional python `range` function?
* How do you retrieve a subset of a list? What is slicing?
* How would you reverse the order of a list? And how would you slice starting at the opposite end?
* What are `pass` and `continue` with respect to a for loop?
* For lists, what are: the `index`, `pop`, `sorted`, `append` and `extend` functions?
* For dicts: how do i iterate through keys, values, and pairs of both?
* When I iterate through a `dict`in a for loop, what is assigned to the index variable?
* In a for loop, if I get an error that says "too many values to unpack", how would I fix that? What does it mean to "unpack"?
* If I have a list of tuples with 3 values, how would I structure the for loop such that there is a variable assigned to each value?
* If I have an iterable with 3 values, how could I write a single line that would unpack all of them into 3 unique variables?
* What is list comprehension? How would I structure this if I had an `if` statement or an `if`/`else` statement?
* Is a `set` an iterable? What is a `frozenset`, and what is the `collections` module?
* What is the difference between `difference` and `symmetric_difference` functions when using a set?
* What is a `while` statement in Python? How would you use this?
* What are itertools? What is `combination_with_replacement` and `product`? Is a `product` object a list?
