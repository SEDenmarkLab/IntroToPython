# Unit 5: Classes and OOP

I would consider this the final less in basic Python that helped me get off the ground to be able to conduct some research. This will deal with the fundamental pieces of Python as they are considered what makes Python "Object-Oriented Programming" (OOP).

Here is a list of questions/comments you should be able to answer:

* What is a class and what is its structure?
* What is object-oriented programming and how do classes enable that?
* How does one initialize a class?
* What are "dunder" or magic methods? How do you use methods like \_\_eq\_\_. \_\_sub\_\_, \_\_str\_\_, and \_\_repr\_\_ to define how standard operators interact with your custom objects?
* What is the `@property` decorator, and how can you use it to prevent a user from setting an invalid value? What is the difference between `.setter` and `.getter`?
* What is the `@classmethod` decorator vs. `@staticmethod` decorator?
* When should you consider using a class over a traditional function?
* What is an instance of a class compared to the class itself?
* What is the `self` argument in an instance method?
* If I wanted to call a method that belongs to a class, what are two ways I could write it?
* What is a class variable vs. an instance (local) variable? Why should you be careful about the uses of variables in classes outside the \_\_init\_\_ method?
* What is encapsulation, and how do we usually signify a private or protected variable within a class?
* What is inheritance for classes? What is a superclass?
* What does the `super` function do, and why is `super().__init__()`almost always the first line in a child class's initialization
* What are singleton objects in Python? What are examples?
* What is a class factory and when would you consider writing one?
* What are the `attrs` and `dataclasses` modules, and how does the syntax change for them?
* How does one use `attrs.field`to modulate defaults for certain arguments? How do you run things with `attrs`after initialization?
* What is a `namedtuple`?
