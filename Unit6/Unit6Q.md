# Unit 6: Auxiliary Packages: Matplotlib, Numpy, Pandas, and Seaborn

We're finally going to use some different packages beyond native Python so you're familiar with some of the more useful tools that we use in our day to day. You are allowed to install/use the Python packages `pandas`, `numpy`, `matplotlib`, and `seaborn`. 

Here is a list of questions/comments you should be able to answer:

### Matplotlib

* What is matplotlib and why do we use it?
* How does one change the fontsize, bold/italicize, and use latex/math text for matplotlib?
* How do I create multiple plots on the same matplotlib plot?
* How do I save a figure? How do figures behave in a Jupyter notebook?
* How do I read, write, append, and close a file in native Python?
* What is the difference between `read` and `readlines`?

### Numpy

* What is `numpy` and why do we use it?
* What is the difference between a numpy array and a traditional list?
* How does one find the minimum, maximum, average, and sort a numpy array?
* What is the `where` function in `numpy`? How would I use it to find specific areas of the array where a condition is met?
