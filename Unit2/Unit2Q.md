# Unit 2: Native Types: Floats, Strings, Ints, and Booleans

Here is a list of questions/comments you should be able to answer:

* What are the differences between floats and integers?
* What does it mean to be "iterable" vs. "non-iterable"? List which of the following are iterable: floats, strings, integers, Booleans
* What does it mean to be "mutable" and "immutable"? Are strings mutable?
* What are the "ceil" and "round" functions for floats? How do they differ, and what are their limitations?
* What integers are also Booleans?
* What is floating point error? What is the difference between a 32-bit float and a 64-bit float? Why might one use one over the other?
* What is an "f-string"? How would you format a float within an f-string to have a certain number of digits? How would you make the float written in an f-string be written with scientific notation instead?
* Be able to explain how strings work when using single quotations/apostrophes vs. triple quotations/apostrophes.
* What is an operator in Python? What is the "%" operator? What is the "//" operator? Are you able to use any operators on strings?
* I decided to add 1 to the variable `x` through the line `x=x+1`. Is there a shorter way to write it?
* What are "if/elif/else" statements, and how do you use them?
* How do you replace a specific character in an existing string (i.e. if I wanted to turn the existing string "abcdef" into the string "abc")? List two ways to do it.
